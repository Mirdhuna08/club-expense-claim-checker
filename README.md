# Club Expense Claim Checker

A web-based application to manage and check
college club expense claims.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite

## Features
- Submit expense claims
- Check expense amounts
- Identify expense categories
- Check bill availability
- Monitor club budgets
- Approve or reject claims

## How to Run

1. Install requirements:
   pip install -r requirements.txt

2. Run the application:
   python main.py

3. Open http://127.0.0.1:5000
